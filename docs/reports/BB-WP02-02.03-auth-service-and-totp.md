## 2. API Endpoints Implemented

| Method | Endpoint | Protection / Middleware | Purpose & Behavior |
|---|---|---|---|
| `POST` | `/api/auth/superadmin/login` | Public (Rate limited) | Authenticates Superadmin credentials; returns session token with `isSecondFactorPending: true`. Returns generic 401 on any failure to prevent user enumeration. |
| `POST` | `/api/auth/superadmin/totp/enroll` | Authenticated (Superadmin, 2FA pending permitted) | Generates unconfirmed 160-bit TOTP secret encrypted with AES-256-GCM. Returns Base32 secret and `otpauth://` URI for QR code presentation. |
| `POST` | `/api/auth/superadmin/totp/confirm` | Authenticated (Superadmin, 2FA pending permitted) | Confirms initial TOTP enrollment with 6-digit code. Generates 8 128-bit recovery codes, hashes them with SHA-256, elevates session to `isSecondFactorPending: false`, and returns plaintext recovery codes once. |
| `POST` | `/api/auth/superadmin/totp/verify` | Authenticated (Superadmin, 2FA pending required) | Verifies 6-digit TOTP within $\pm 1$ step. Rejects replayed codes ($T \le \text{lastAcceptedStep}$). Elevates session on success. Implements 5-attempt / 15-minute lockout. |
| `POST` | `/api/auth/superadmin/totp/recovery` | Authenticated (Superadmin, 2FA pending required) | Authenticates with a 128-bit recovery code. Atomically consumes and removes code hash. Elevates session. Implements 5-attempt / 15-minute lockout. |
| `POST` | `/api/auth/change-password` | Authenticated (Active session) | Verifies existing password, hashes new password with native `bcrypt` (12 rounds), clears `mustChangePassword: false`, and revokes all other user sessions. |
| `POST` | `/api/auth/logout` | Authenticated | Revokes current session token and clears the `bb_session` HTTP-only cookie. |
| `GET` | `/api/auth/me` | Authenticated | Returns sanitized user profile, role, session expiration, and 2FA / password change status flags. |

## 3. Cryptographic & Security Architecture

### A. TOTP Replay Prevention & Concurrency Safety
- Standard RFC 6238 time-step is derived as $T = \lfloor \text{Date.now()} / 30000 \rfloor$.
- Any code matching a time-step $T \le \text{userTotp.lastAcceptedStep}$ is strictly rejected with `TOTP_CODE_REUSED` (HTTP 400).
- Concurrency race conditions are eliminated using Prisma atomic conditional updates:
  ```javascript
  const updateResult = await prisma.userTotp.updateMany({
    where: {
      id: totp.id,
      OR: [
        { lastAcceptedStep: null },
        { lastAcceptedStep: { lt: matchedStep } }
      ]
    },
    data: {
      lastAcceptedStep: matchedStep,
      failedAttempts: 0,
      lockedUntil: null
    }
  });
  if (updateResult.count === 0) {
    throw new ApiError(HTTP_STATUS.BAD_REQUEST, 'TOTP code has already been used.', ERROR_CODES.TOTP_CODE_REUSED);
  }
  ```

### B. Brute-Force Lockout Defense
- 5 consecutive failed TOTP verification attempts or invalid recovery code attempts set `lockedUntil = now + 15 minutes` in PostgreSQL.
- Any subsequent attempt during the lockout period is rejected with `ACCOUNT_LOCKED` (HTTP 423) and headers indicating the lockout status.

### C. Emergency Recovery Code Lifecycle
- 8 emergency recovery codes generated via `crypto.randomBytes(16)` (128 bits of CSPRNG entropy each).
- Stored exclusively as SHA-256 hashes of the normalized 32-character string.
- Verified in constant-time using `crypto.timingSafeEqual`.
- Single-use consumption: matching hash is atomically spliced from the array and persisted. The code cannot be reused.

### D. Session Security & Dual Delivery
- Sessions support both `Authorization: Bearer <token>` and `Cookie: bb_session=<token>` (`httpOnly`, `SameSite=Lax`, `path=/`, `maxAge=12h`).
- Sessions are hashed via SHA-256 (`session.tokenHash`) before database lookup.
- 30-minute sliding idle timeout (`IDLE_TIMEOUT_MS = 30 * 60 * 1000`) refreshed on authenticated requests.
- 12-hour hard absolute timeout (`ABSOLUTE_TIMEOUT_MS = 12 * 60 * 60 * 1000`) calculated from `createdAt`.
- Revocation flag `isRevoked` immediately invalidates sessions upon logout or password reset.
