## J. Architecture Observations
- **Prisma Version Alignment:** Prisma 7 enforces `prisma.config.ts` and requires driver adapters for connection strings. Because this project strictly prohibits TypeScript files (`.ts` / `.tsx`), `prisma@6.19.3` was selected as the stable LTS version that natively supports `url = env("DATABASE_URL")` in standard `schema.prisma` for pure JavaScript ES Modules.
- **Express 5 Native Promises:** Express 5 handles rejected promises in async middleware and route handlers automatically without requiring `express-async-errors` or manual `try/catch(next)` wrappers.
- **Node.js Native Watch Mode:** The `dev` script uses Node 22's built-in `node --watch src/server.js`, eliminating unnecessary dev dependencies like `nodemon`.
